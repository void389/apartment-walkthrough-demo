# Warm Modern Apartment — interactive concept walkthrough

This browser-based 3D concept follows the supplied Option 06 plan and design reference deck. It includes room-by-room camera views, a foldable TV-room screen, one-click PNG export for the current view, and nine pre-rendered stills in `stills/`.

## Run locally

Serve this directory with any static web server and open `index.html`. Module imports do not run reliably from a `file://` URL.

## Scope

Geometry is an interpretive design-intent model based on the supplied plan, not a construction or measurement document. The package contains no external runtime dependencies and can be shared as a static site.
